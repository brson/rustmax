Rustmax 0.0.13 is released.


## `rustmax rmxdoc`

`rustmax rmxdoc` generates API docs in HTML format
with Rustmax's custom renderer.
It documents the current workspace:
it runs `cargo doc` with a nightly toolchain
and renders the JSON that cargo produces.
It takes cargo's `-p`, `-F`, `--all-features`,
`--no-default-features` and `--no-deps`.
`--json PATH` renders existing JSON.
`--std` also renders the standard libraries.

Items in crates that are not rendered
link to their docs on docs.rs and doc.rust-lang.org
instead of being plain text.


## A guide for coding agents

`rustmax agents` prints a guide for coding agents
working in a project that uses `rustmax`.
It covers reaching re-exported crates through `rmx::`,
which derives and macros work through `rustmax`,
choosing and extending profiles,
and the compiler errors that show up most often in rustmax projects.
The same text is published at
<https://rustmax.net/agent-guide.md>.

Projects created from the template now include an `AGENTS.md`
that points agents at the guide.


## `rmx::rand::rng()` in `rmx-profile-portable`

`rand`'s `thread_rng` feature is now enabled in `rmx-profile-portable`,
so `rmx::rand::rng()` is available there,
including on `wasm32-unknown-unknown`.
