Rustmax 0.0.14 is released.


## A smaller prelude

`rmx::prelude` no longer re-exports
the standard library prelude,
`core::cmp::Ordering`,
`futures::prelude`,
or the `format!` and `vec!` macros.
It now holds only items from the re-exported crates
and from `rustmax` itself.


## Tool status and updates

`rustmax tools-status` now reads installed versions
from cargo's own install records
and checks crates.io for the latest ones,
printing one line per tool with whether it is out of date.
Before, it ran each tool with `--version`,
which failed or printed noise for several of them.

`rustmax update-tools` only reinstalls tools that are out of date
or whose binaries have gone missing,
instead of rebuilding every tool.
`update-tool mold` no longer installs mold when it is missing,
and installing or updating mold no longer rewrites
a cargo config that already uses it.


## Rendering fixes

`rustmax rmxdoc` resolves glob re-exports to the module they name,
rather than listing the whole root of the crate the module is in,
and no longer makes a page for items re-exported `as _`.

`rustmax rmxbook`, which renders the books in the
[library](https://rustmax.net/library/),
now handles much more of what mdbook does:
images and other assets, nested summaries,
`{{#include}}` and related directives,
hidden lines in Rust examples, and cross-book links.

Both of these improve the website documentation experience.
