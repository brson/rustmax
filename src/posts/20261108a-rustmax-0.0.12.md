Rustmax 0.0.12 is released with 28 commits since 0.0.11.


## `rustmax browse`

The new `rustmax browse [WORKSPACE]` command
generates a static, cross-referenced source browser for a cargo workspace,
written to `target/rmxbrowse`.

It indexes the workspace with `rust-analyzer scip`,
then writes a highlighted page for every source file
and a listing for every directory.
Every identifier that rust-analyzer resolves is a link:
workspace items go to their definitions,
and items from dependencies and std go to docs.rs or doc.rust-lang.org
at the version that was actually resolved.
Hover cards show signatures and docs,
definitions list their references,
source pages have a collapsible item outline,
and there is search over symbols and files.
The root page draws the dependency graph of the workspace,
package pages summarize their files and items,
and a dependency usage page shows which external items the workspace uses.
With `--rustdoc`, rustdoc JSON adds trait and impl navigation.
The site works from `file://` URLs, so no server is needed.


## `#[rmx::tokio::main]` and `#[rmx::tokio::test]`

These macros now work through `rustmax` alone:

```rust
#[rmx::tokio::main]
async fn main() {
    // ...
}
```

Before, they failed with "cannot find module or crate `tokio`"
unless `tokio` was also a direct dependency.


## Crate changes

Removed:

- `cxx` and `cxx-build` -
  the `cxx::bridge` macro only works when `cxx` is a direct dependency,
  so re-exporting it was not useful.
  Depend on `cxx` and `cxx-build` directly.

Upgraded:

- `comrak` 0.57 → 0.59

Also, `rand`'s `StdRng` is now available in `rmx-profile-portable`.


## Folio

The demo app is renamed from Anthology to Folio,
so it no longer collides with `rustmax-anthology`,
the collection of archived Rust blog posts.
It is now a working document publisher.
It has `folio watch` and `folio serve` with live reload,
reproducible builds and exports,
working search,
and `folio check`, which checks links, images and `#fragment` anchors.


## Also

- The `rustmax-prebuild` crate is folded into the CLI as `rustmax build-www`.
- The crate table uses themable SVG icons instead of emoji.
- The CI toolchain is Rust 1.97.1.
