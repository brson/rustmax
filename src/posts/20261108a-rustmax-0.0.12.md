Rustmax 0.0.12 is released.


## `rustmax browse`

The new `rustmax browse` command
generates a static,
cross-referenced source browser for a cargo workspace,
written to `target/rmxbrowse`.

It indexes the workspace with `rust-analyzer scip`,
With the `--rustdoc` flag,
which requires nightly,
it adds trait and impl navigation using rustdoc's JSON.


## `#[rmx::tokio::main]` and `#[rmx::tokio::test]`

These macros now work through `rustmax` alone:

```rust
#[rmx::tokio::main]
async fn main() {
    // ...
}
```

Before, they failed with "cannot find module or crate `tokio`"
unless `tokio` was also a direct dependency.


## Crate changes

Removed:

- `cxx` and `cxx-build` -
  the `cxx::bridge` macro only works when `cxx` is a direct dependency,
  so re-exporting it was not useful.

Upgraded:

- `comrak` 0.57 → 0.59

Also, `rand`'s `StdRng` is now available in `rmx-profile-portable`.
